One word, and nothing else: the word grandma would text about AI. This
entry scores ten candidate words against the judge's brief -- grandma's
texting voice first, then warm and a little baffled, funny in one word,
tied to AI, fresh and instantly readable -- and writes the winner to
`entry.txt`. The winner is **Robit**: her typo for "robot", warm,
baffled, funny on its own, and unmistakably about a machine.

## Run it

```sh
python3 main.py
```

That prints the winning word and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when unset).
The program is pure Python standard library: no network, no clock, no
randomness, so two runs are byte-identical.
See every candidate, best first, with `python3 main.py --all`, or with
scores via `python3 main.py --scores`. Run the tests with
`python3 -m unittest test_main -v`.
